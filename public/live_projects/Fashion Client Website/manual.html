📖 Introduction

Welcome to the AG Fashion Hub Content Management System. This manual will guide you through managing your website content efficiently and safely.

Important: Changes you make in the CMS appear on the live website immediately after saving. Always double-check your content before publishing!

Content Types You Can Manage

  • Dress Collections - Categories of clothing (e.g., "Sarees", "Lehengas")
  • Dress Designs - Individual products within collections
  • Blog Posts - Articles and updates for your customers
  • Announcements - Site-wide banners for promotions and updates
CMS URL: https://cms.amitojenterprisesltd.ca/wp-admin

🔐 Logging In

Steps to Access Your CMS

  1. Open your web browser (Chrome, Safari, or Firefox recommended)
  2. Go to: https://cms.amitojenterprisesltd.ca/wp-admin
  3. Enter your username
  4. Enter your password
  5. Click "Log In"
⚠️ Security Tips:
  • Never share your login credentials
  • Use a strong password (at least 12 characters)
  • Always log out when finished, especially on shared computers
  • If you forget your password, click "Lost your password?" on the login page

📁 Managing Dress Collections

Collections are categories that group similar products together (e.g., "Wedding Sarees", "Party Lehengas").

Adding a New Collection

  1. Click "Pods Admin" → "Dress Collections"
  2. Click "Add New" at the top
  3. Fill in all required fields (see table below)
  4. Click "Publish" when ready

Collection Fields Guide

Field Name Required Description Example Common Errors
Title ✅ Yes Main collection name Wedding Lehengas ❌ Don't use special characters like @, #, $
Collection Name ✅ Yes Display name on website Wedding Lehengas Collection ❌ Don't leave blank
Hero Image ✅ Yes Main image for collection card Upload high-quality image ❌ Don't use images smaller than 800x600px
Description ⚠️ Optional Brief description Elegant wedding lehengas for your special day Keep under 200 characters
Meta Title ⚠️ Optional SEO title for search engines Wedding Lehengas - AG Fashion Hub Keep under 60 characters
Meta Description ⚠️ Optional SEO description Browse our exclusive collection... Keep under 160 characters
⚠️ Critical Errors to Avoid:
  • ❌ Never leave "Title" or "Collection Name" blank
  • ❌ Don't use duplicate collection names
  • ❌ Don't delete collections that have designs linked to them

👗 Managing Dress Designs (Products)

Designs are individual products that appear on your website.

Adding a New Design

  1. Click "Pods Admin" → "Dress Designs"
  2. Click "Add New"
  3. Fill in all required fields
  4. Click "Publish"

Design Fields Guide

Field Name Required Description Example
Title ✅ Yes Product name Red Bridal Lehenga
Design Code ✅ Yes Unique product code AG-LEH-001
Design Gallery ✅ Yes Product images (3-10 images) Upload multiple photos
Price ⚠️ Optional Product price (numbers only!) 299.99
Linked Collection ✅ Yes Select collection from dropdown Choose from list
Availability ⚠️ Optional CHECKBOX - Check for In Stock ✅ = In Stock, ❌ = Out of Stock
Show in New Arrivals ⚠️ Optional Feature on homepage ✅ = Featured
🚨 CRITICAL: Most Common Errors

❌ DON'T

  • Use duplicate design codes
  • Include $ in price (just 299.99)
  • Type "In Stock" as text
  • Upload less than 3 images
  • Leave collection unselected

✅ DO

  • Use unique codes (AG-001, AG-002)
  • Enter price as numbers only
  • Use the checkbox for availability
  • Upload 3-10 quality images
  • Always select a collection
📌 Remember: The Availability field is a CHECKBOX, not a text field! Check the box for "In Stock", leave unchecked for "Out of Stock".

📝 Managing Blog Posts

Creating a New Blog Post

  1. Go to "Posts" → "Add New"
  2. Enter your post title
  3. Write your content in the editor
  4. Set a featured image (click "Set featured image" in the right panel)
  5. Select categories and tags
  6. Click "Publish"

Blog Writing Tips

  • Start with an engaging introduction
  • Use subheadings to break up content
  • Include relevant product links
  • Add high-quality images throughout
  • End with a call-to-action (e.g., "Shop the collection")

📢 Managing Announcements

Announcements are site-wide banners displayed at the top of your website pages.

Creating an Announcement

  1. Go to "Pods Admin" → "Announcements"
  2. Click "Add New"
  3. Fill in the required fields
  4. Check the "Is Active" box to display it
  5. Set the Priority (higher numbers show first)
  6. Click "Publish"
Field Purpose Example
Title Internal reference (not shown to users) Holiday Sale 2025
Message Text displayed in banner 🎉 Holiday Sale - 30% OFF on all items!
Type Visual style (info/warning/error/success) success (for promotions)
Is Active Controls visibility ✅ Checked = Shows on website
Priority Display order 10 (higher = shows first)

💬 WhatsApp Inquiry Feature

Each product automatically includes a WhatsApp inquiry button that pre-fills a message with product details.

What Gets Sent

  • Product name and code
  • Direct link to the product
  • Price (if set)
  • Pre-written inquiry message
💡 Tip: Always test the WhatsApp button after adding a new product to ensure the design code and price are correctly formatted.

🖼️ Image Upload Guidelines

Image Requirements

Aspect Requirement Best Practice
Format JPG, PNG, or WebP Use JPG for photos, PNG for graphics
Minimum Size 800x800px 1200x1200px or larger recommended
File Size Under 5MB per image Optimize to 200-500KB for fast loading
Quality Clear, well-lit photos Professional photography preferred

Optimization Steps

  1. Use an image editing tool to resize (maintain aspect ratio)
  2. Compress images using tools like TinyPNG or Squoosh
  3. Name files descriptively (e.g., "red-bridal-lehenga-front.jpg")
  4. Ensure consistent lighting and background across product photos

⚠️ Common Errors & How to Avoid Them

Error 1: Duplicate Design Codes
Problem: Using the same code for multiple products
Solution: Each product must have a unique code (AG-001, AG-002, AG-003, etc.)
Error 2: Price Formatting Issues
Problem: Including $ symbol or text in price field
Wrong: $299.99, CAD 299, 299 dollars
Correct: 299.99 (numbers only)
Error 3: Availability Field Confusion
Problem: Trying to type "In Stock" as text
Solution: It's a CHECKBOX! Check = In Stock, Unchecked = Out of Stock
Error 4: Insufficient Gallery Images
Problem: Uploading less than 3 images
Solution: Always upload 3-10 high-quality images per product
Error 5: No Collection Selected
Problem: Leaving "Linked Collection" field empty
Solution: Always select a collection from the dropdown
