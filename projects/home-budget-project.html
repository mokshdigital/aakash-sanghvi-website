THE STORY BEHIND

Why I Built This

Like many people, I found myself constantly wondering where my money was going. Spreadsheets were tedious, and existing apps were either too complex or lacked the specific features I needed for my household workflow.

I wanted something that truly fit my needs—a clean, intuitive budget tracker that gives me complete visibility into my home expenses, income, and savings at a glance.

"I wanted to build something I would actually use every day — not just another portfolio project that sits in a GitHub repo collecting dust."
— MY GUIDING PRINCIPLE

The Challenge & Solution

Existing solutions were either too simple or too complex. I needed the Goldilocks zone.

🎯

The Problem

Existing budget apps were either too simple (just expense tracking) or too complex (full accounting suites). I needed ease of use + power.

💡

The Solution

A modern web app with separate tracking for expenses, income, and savings. Quick data entry forms and beautiful visualizations.

🚀

The Impact

I now have complete visibility into my finances. Data entry takes seconds, and the app has become an essential part of my daily routine.

Technical Challenges

CHALLENGE

Date Filtering Accuracy

Transactions weren't appearing in "This Month" due to timezone offset issues when parsing ISO strings.

SOLUTION

Implemented local timezone-aware parsing by splitting YYYY-MM-DD strings and constructing explicit Date objects.

CHALLENGE

Real-time Auth State

Syncing auth state across Server Components, Client Components, and API routes in Next.js 15.

SOLUTION

Implemented separate Supabase client factories for browser, server, and middleware contexts using @supabase/ssr.
